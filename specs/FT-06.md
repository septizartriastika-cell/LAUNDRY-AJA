# FT-06 Tombol Kirim ke WhatsApp

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-06), Bagian 7 (Template Pesan WhatsApp), Bagian 8 (AC-05), Bagian 9 (TC-03, TC-04, TC-05)

## Tujuan
Pengguna dapat memvalidasi seluruh isian pesanan dan langsung membuka obrolan WhatsApp toko berisi draf rincian pesanan yang terformat rapi.

## Alur
1. Pengguna menekan tombol **Kirim Pesanan ke WhatsApp**.
2. Sistem memeriksa kelengkapan paket, estimasi berat, nama pelanggan, dan alamat (jika Antar-Jemput aktif).
3. Jika ada kolom yang tidak sah, sistem menampilkan pesan error di bawah kolom terkait dan memindahkan fokus ke kolom error pertama.
4. Jika semua kolom sah, sistem menyusun template pesan WhatsApp, melakukan URL-encoding, membuka `https://wa.me/<NOMOR>?text=<PESAN>` di tab baru (`target="_blank"`, `rel="noopener noreferrer"`), dan menampilkan tautan cadangan di layar jika browser membatasi tab baru.

## Data
- `STORE_CONFIG.whatsappNumber`: `"6281234567890"` (format internasional angka saja `62xxx`).
- Hasil rincian biaya dari **FT-04** dan data pemesan dari **FT-05**.

## Aturan dan rumus
- Urutan pemeriksaan validasi saat kirim:
  1. Paket terpilih tersedia (`selectedPackage != null`).
  2. Berat aktual sah dan `>= 0,1` serta `<= 100`.
  3. Nama pelanggan setelah di-trim memiliki panjang `>= 2`.
  4. Jika `Antar-Jemput` aktif, alamat penjemputan setelah di-trim tidak kosong.
- Urutan pemindahan fokus saat error: Berat -> Nama Lengkap -> Alamat Penjemputan.
- Template pesan WhatsApp wajib dari PRD Bagian 7 (nilai di pesan harus sama persis dengan angka di layar):

```text
Halo Admin Laundry, saya ingin memesan layanan dengan rincian berikut:

*Nama:* [Nama Pelanggan]
*Paket Layanan:* [Nama Paket] (Rp [Tarif]/kg)
*Estimasi Berat:* [Berat Aktual] kg (Berat Ditagih: [Berat Ditagih] kg)
*Layanan Tambahan:*
- Antar-Jemput: [Ya (+Rp 10.000) / Tidak]
- Pewangi Premium: [Ya (+Rp BiayaPewangi) / Tidak]

*Alamat Penjemputan:* [Alamat Lengkap / Antar Sendiri ke Toko]
*Catatan Khusus:* [Catatan Khusus / -]

*Estimasi Total Biaya:* *Rp [Total Estimasi]*

_(Catatan: Nominal di atas merupakan estimasi awal. Berat pasti akan ditimbang ulang saat pakaian diterima oleh kurir/kasir toko)._

Mohon konfirmasi jadwal dan ketersediaannya. Terima kasih!
```

- Proses URL: `https://wa.me/${whatsappNumber}?text=${encodeURIComponent(message)}`.

## Input dan validasi
- Tombol bertipe `submit` dengan tinggi minimal `44 px`, label `Kirim Pesanan ke WhatsApp`.
- Tidak boleh memicu navigasi WhatsApp selama masih ada satu pun kesalahan validasi.

## Tampilan dan teks
- Tombol utama memakai warna `bg-orange-700 hover:bg-orange-800 text-white`.
- Setelah pengiriman berhasil, tampilkan kotak status hijau (`bg-emerald-50 text-emerald-800`) berisi konfirmasi singkat dan tautan `<a target="_blank" rel="noopener noreferrer">` untuk membuka ulang WhatsApp bila diperlukan.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-05 | Semua kolom sah (Nama `"Rina"`, Cuci Lipat, berat `3` kg) | URL `https://wa.me/6281234567890?text=...` terbentuk dengan isi sama seperti layar | PRD AC-05 |
| TC-03 | Berat `0` kg, Nama `"Rina"` | Validasi gagal pada berat, fokus ke kolom berat, WA tidak dibuka | PRD TC-03 |
| TC-04 | Antar-Jemput `true`, Nama `"Budi"`, Alamat `""` | Validasi gagal pada alamat, fokus ke kolom alamat, WA tidak dibuka | PRD TC-04 |
| TC-05 | Catatan `"Baju putih & batik (jangan dicampur!), telp #2"` | Parameter `text` ter-encode utuh sehingga simbol `&` dan `#` tidak memutus pesan | PRD TC-05 |
| FT06-B1 | Antar-Jemput `false`, Catatan kosong | Pesan WA memuat `Antar Sendiri ke Toko` untuk alamat dan `-` untuk catatan | Tambahan |

## Di luar lingkup
- Pengiriman pesan otomatis melalui WhatsApp Business API dari server.
- Pelacakan status apakah pesan benar-benar jadi dikirim oleh pengguna di aplikasi WhatsApp.
